# Anime Player

(empty)

## [S1] Problem
Пользователь хочет смотреть аниме (Токийский гуля, сезон 1) на минималистичном сайте с удобным выбором озвучки, сезона и серии. Видео и озвучка могут быть как в одном файле, так и раздельно. Пока данные захардкожены (ссылки на S3).

## [S2] Design
- **Техстек**: React + Vite + TypeScript + Plyr
- **Дизайн**: тёмная тема, красно-багровый акцент (#9b1b30), минимализм
- **Layout**: плеер по центру экрана, контролы под плеером
- **Данные**: захардкоженный массив эпизодов в `src/data/episodes.ts`
- **Структура данных**:
  - Каждый эпизод: `{ id, season, episode, title, sources: Voiceover[] }`
  - Каждая озвучка: `{ name, videoSrc, audioSrc? }` — `audioSrc` опционален (если аудио отдельно от видео)
  - Если `audioSrc` есть — Plyr получает отдельный видеопоток + аудиопоток
  - Если `audioSrc` нет — Plyr получает один файл (видео+аудио вместе)
- **Поведение плеера**:
  - При смене озвучки — переключаем `src` (и `audioSrc` если есть)
  - При смене серии — переключаем эпизод
  - Plyr встроен через `useRef` + `useEffect`
- **UI контролы**:
  - Dropdown для выбора сезона (пока только Season 1)
  - Dropdown/список для выбора серии (1-12)
  - Dropdown/pills для выбора озвучки

## [S3] Out of Scope
- Авторизация, плейлисты, избранное
- Субтитры
- Адаптивность под мобилки (пока)
- Интеграция с API (AniLibria, Kodik и т.д.)
- Серверная часть, SSR
